# 使用指南（逐屏）

> 面向"只想用，不想配置"的人。安装包解压后双击 `starforge.exe` 即可，不需要 Python、不需要浏览器。

---

## 0. 安装与首次启动

1. 从 Releases 下载 `starforge-<版本>-win64.zip`，解压到任意目录（**不要**放进游戏目录）。
2. 双击 `starforge\starforge.exe`。
   > **命令行在哪**：双击 `starforge.exe` 不会出现黑控制台；命令行请用同目录的
   > `starforge-cli.exe <子命令>`（`starforge.exe <子命令>` 也会转发，但终端输出以 `starforge-cli.exe` 为准）。
   - 启动器会直接打开应用窗口，不再显示控制台；重复双击会前置已有窗口（单实例锁）。
   - 左侧导航按「探索 / 资料 / 连接」分组：概览、飞船实验室、设计器 / 我的船队、星图 / 游戏内代理、设置。
3. 首次启动若缺少路径，会弹**三步配置向导**：
   - 点「自动检测」：多数情况会直接填好游戏目录与存档目录；
   - 也可点「浏览…」用系统对话框选择；
   - 点「保存并检查」，顶栏的状态芯片会变绿。
4. 顶栏状态芯片含义：

| 芯片 | 绿 | 黄/红 |
|---|---|---|
| 数据层 | 内置数据层可用 | 缺失（用命令行跑 `selftest` 看原因） |
| 部件目录 | 能读到部件表（Gagarin 数据或游戏资源推导） | 都没读到 |
| 存档 | 找到存档目录并能解析 | 未找到（可手选） |
| 游戏 | 找到 `Binaries/NMS.exe` 与 `PCBANKS` | 未设置（3D 只能看部件图） |
| 写入 | 已在设置里允许写入 | 默认关闭 |

> 应用启动后会在后台**预热**（解包元数据 / 建一艘船的几何 / 跑一次系统生成，约 2 秒），
> 之后第一次点 3D 不用再等 5 秒。

## 1. 搜飞船

**目标**：按"长什么样"找到种子。

1. 左上「船型」选一种（8 种程序化船型）。
2. 「部件」区点任意部件：**点一下变绿＝想要**，再点一下变灰；切到「不要」再点＝排除。
   - 上方输入框可按名字过滤（如 `PIT`、`WING`）。
   - 选中的部件会显示在「部件」框下方。
3. 右侧会显示估算：*约 1 in N 个种子命中 · 预计 X 秒（单核）*。
   - 「并行线程」默认不超过 min(4, CPU)；设置页的「搜索线程数」可作为默认值（0 = 自动）。
4. 选「搜索预算」后点「开始搜索」：
   - 顶栏出现进度条（已测种子数 / 速率）；
   - 结果以卡片网格出现，每张可看到缩略图。
5. 点任意卡片 → 右侧出现**可拖动旋转的 3D**（等轴/俯视/侧视/自转、滚轮缩放），颜色是这艘船的**真实配色**。
6. 右上角按钮：
   - `复制种子` / `分享码`（`nsh1:…`，别人可在「导入分享」里还原）
   - `收藏`（★ 收藏夹可管理/载入；收藏夹入口在页头）
   - `查星系`（种子→星系反查，打开对话框显示候选/符文）
   - `写入存档`（同型换种子，见第 4 节）
   - `导出 glb`（可拖进 Blender）
7. 结果区可多选 2–3 艘「加入对比」，再点「对比」并排查看；上方有「清空对比」。
8. 「收藏夹」按钮打开收藏列表；结果栏可清空当前结果。

**快捷键**：`Ctrl+Enter` 搜索 · `Ctrl+F` 聚焦筛选 · `j`/`k` 上下选结果 · `1`–`4` 切视角 · `Esc` 清除结果选中。

## 2. 我的船队

1. 左侧「读取」（路径会自动带出，也可点「浏览…」选文件）。
2. 列表每艘显示：名称 · 类型 · 等级（S/A/B/C） · 四项属性 · 是否可预览。
   - 缩略图区可选「只看能预览的」。
   - 固定模型（护卫舰/复古拦截机等）标「固定模型」，没有 3D，显示占位图。
3. 点任意一艘 → 右侧 3D + 属性条 + 部件缩略图。
4. 标签页：`飞船` / `同伴` / `护卫舰` / `工具` / `货船`。
   - 同伴、护卫舰、多用途工具、货船目前是**只读**；没有稳定写回 API 的内容不会伪造入口。
5. 页头操作：
   - `备份恢复`：查看/恢复已有备份；
   - `船级/属性…`（选中飞船后）：改等级/属性，走备份、确认、读回、回滚；
   - `存档编辑…`：货币与飞船名称/涂装；
   - `扩展编辑…`：库存、词语/知识、任务、奖励；
   - `批量导出`：把当前列表导出成 zip（glb + png + 清单）。
6. 所有写操作默认「写入副本」，也可在对话框里取消勾选改为写原档；失败自动回滚。

---

## 3. 设计器

1. 左侧选择船型和部件（每组一个），中间实时 3D 预览。
2. 「用这些部件搜索种子」→ 结果列表里选一个种子，3D 会更新。
3. `保存设计…` / `载入设计…` 使用本地 `.nmsdesign.json`，**不写存档**。
4. `写入存档…` 可选择：
   - 新建飞船（第一个空槽）；
   - 替换现有槽位；
   - 可选「同时涂装」（主色/副色/调色板，仅槽位 0–11）。
5. 写入会先备份、二次确认、写后读回校验，失败回滚；默认写入副本。

---

## 4. 写回存档（同型换种子）

前提：设置里打开「允许写入」。

1. 在「搜飞船」里选中一艘想要外观的船 → `写入存档`。
2. 弹窗列出**同型**的船（不同船型的部件树不同，不能跨型），选目标槽位。
3. 确认后：自动备份 → 原子写入 → **重新解码核对** → 成功提示（附备份路径）。
4. 想更保守：勾选「写入副本」时不动原档，生成 `save.edited.hg`；确认满意后改名成 `save.hg` 再进游戏。
5. 失败会自动**回滚**，并告诉你备份在哪。

## 5. 星球

1. 进入页面即自动读取**当前星系**（来自存档位置）：坐标、glyphs、星系名、种族、行星数、是否 dissonant、拦截机种子。
2. 行星卡片按生物群系配色，**"你在这里"**标出当前所在行星。
3. 右侧是本星系船池（空间站/货船/护卫舰/哨兵/海盗/虫群），带种子，可点「3D」直接看。
4. 「扫描」：选生物群系 / 哨兵等级 / 种族 / 是否要拦截机 → 扫描附近星系；结果会写入银河索引。页面有「取消扫描」，但当前子进程尚未接收取消事件，可能跑完本次扫描。
   - 结果表每行有 glyphs；选中后可复制符文或 `浮窗显示符文`（独立置顶窗，不注入游戏，`Esc` 关闭）。
5. 「银河索引」标签：按条件查询已扫描的星系，可导出 CSV。
6. 「地址工作台」：输入 12 位符文串或 `0x…` 种子做反查；候选可复制符文或填入游戏内传送输入（仅界面状态）。

## 6. 游戏内通道（可选，Windows）

先启动游戏并载入存档，再到「游戏内代理」页：

1. `连接游戏`（或 `启动游戏并注入`）：准备运行时 → 安装/更新组件 → 注入并连接。
2. 状态卡显示运行时/Mod/Agent 三步；版本卡显示 build 是否已验证。
3. `外部内存只读探测`：只读查看模板槽候选；多候选同样可信时不会写入。
4. 实时遥测：玩家 / 当前星系 / 当前行星 / 游戏内船槽。
5. 安全区：传送、还原、读取当前行星扫描；高风险操作受 build 与多人闸门限制，未验证版本自动只读。
6. `停止注入器` 可停止；运行失败可点 `修复运行时/游戏内组件`。

> agent 使用启动时生成的一次性 token（通过 `?token=` 传递）；固定端口 5000 启动前会做冲突检测。
> 传送前会持久化快照，写后轮询位置读回；未确认不会伪造成功。
>
> **模板槽“送进游戏”目前没有原生页面入口**（`live_push/live_template_mod` 仅在 Web API 调试路由），且 agent 写操作尚未 Windows 实机验证。

## 7. 设置与诊断

- 路径卡显示 ✓/✗ 与原因；「自动检测」会顺便纠正常见填错（选到 `GAMEDATA`、`Binaries`、甚至 Steam 根目录）。
- 安全与性能：`允许写入存档`、`写入前二次确认`、`备份保留数`、`搜索线程数`。
- 版本与代理：显示 build 指纹与 agent 状态；可 `复制最近日志` / `查看 launcher.log 摘要`。
- 诊断：`运行体检`、`导出诊断包`（ZIP：health / doctor / selfcheck / build / agent / 脱敏设置 / 日志）、`打开日志目录`。
- 命令行等价物（同一个 exe）：

```bat
starforge.exe selfcheck          :: 端到端自检（写入只在存档副本上）
starforge.exe selftest           :: 基础自检
starforge.exe webcheck           :: 只验证 API 与关键接口
starforge.exe ships              :: 列存档里的船
starforge.exe saves              :: 扫描存档目录
starforge.exe settings           :: 查看/修改设置
starforge.exe doctor             :: 环境体检
starforge.exe agent              :: agent hello / 能力表
starforge.exe live probe         :: 只读探测模板槽
starforge.exe glyph-overlay 1043FEE69929 --click-through
```

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 顶栏「游戏」是红的 | 设置页确认游戏目录指向含 `Binaries` 的那层；点「自动检测」 |
| 3D 区显示"3D 不可用（已用渲染图代替）" | 说明游戏目录没配好或 pak 读不到；看设置页的 ✓/✗ |
| 「我的船队」读不到 | 确认存档目录含 `save.hg`；`accountdata.hg` / `mf_*.hg` 不是玩家存档 |
| 写回按钮是灰的 | 设置里打开「允许写入」 |
| 符文显示成字母 | 缺 BC7 解码器（发布包已内置 `texture2ddecoder`）；源码运行时 `pip install texture2ddecoder` |
| 双击没有窗口 | 已改为原生 Qt，不再依赖 WebView2；先看 `%USERPROFILE%\.starforge\logs\`，可设 `STARFORGE_SAFE=1` 用软件 OpenGL 启动 |
| 重复双击没有新窗口 | 单实例锁会把已有窗口前置；确认没有旧进程后重试 |
| 想彻底卸载 | 删程序目录；`%USERPROFILE%\.starforge`（设置/缓存）与存档旁的 `.bak` 自行决定保留 |
