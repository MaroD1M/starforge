# 使用指南（逐屏）

> 面向"只想用，不想配置"的人。安装包解压后双击 `starforge.exe` 即可，不需要 Python、不需要浏览器。

---

## 0. 安装与首次启动

1. 从 Releases 下载 `starforge-<版本>-win64.zip`，解压到任意目录（**不要**放进游戏目录）。
2. 双击 `starforge\starforge.exe`。
   - 黑控制台会自动隐藏，直接出现应用窗口（标题「无人深空 · 飞船猎人」）。
   - 若系统缺 WebView2，会自动改用浏览器打开，并在日志里说明。
3. 首次启动若缺少路径，会弹**三步配置向导**：
   - 点「自动检测」：多数情况会直接填好游戏目录与存档目录；
   - 也可点「浏览…」用系统对话框选择；
   - 点「保存并检查」，顶栏的状态芯片会变绿。
4. 顶栏状态芯片含义：

| 芯片 | 绿 | 黄/红 |
|---|---|---|
| 数据层 | 内置数据层可用 | 缺失（用命令行跑 `selftest` 看原因） |
| 部件目录 | 能读到部件表（Gagarin 数据或游戏资源推导） | 都没读到 |
| 存档 | 找到存档目录并能解析 | 未找到（可手选） |
| 游戏 | 找到 `Binaries/NMS.exe` 与 `PCBANKS` | 未设置（3D 只能看部件图） |
| 写入 | 已在设置里允许写入 | 默认关闭 |

> 应用启动后会在后台**预热**（解包元数据 / 建一艘船的几何 / 跑一次系统生成，约 2 秒），
> 之后第一次点 3D 不用再等 5 秒。

---

## 1. 搜飞船

**目标**：按"长什么样"找到种子。

1. 左上「船型」选一种（8 种程序化船型）。
2. 「部件」区点任意部件：**点一下变绿＝想要**，再点一下变灰；切到「不要」再点＝排除。
   - 上方输入框可按名字过滤（如 `PIT`、`WING`）。
   - 选中的部件会显示在「部件」框下方。
3. 右侧会显示估算：*约 1/N 的种子满足 · 预计 X 秒*。
4. 选「搜索预算」后点「开始搜索」：
   - 顶栏出现进度条（已测种子数 / 速率）；
   - 结果以卡片网格出现，每张可看到缩略图。
5. 点任意卡片 → 右侧出现**可拖动旋转的 3D**（等轴/俯视/侧视/自转、滚轮缩放），颜色是这艘船的**真实配色**。
6. 右上角按钮：
   - `复制种子` / `分享码`（`nsh1:…`，别人可在「导入」里还原）
   - `写回存档…`（同型换种子，见第 3 节）
   - `送进游戏`（仅 Windows 且游戏在运行时出现，见第 5 节）
   - `glb`（下载模型，可拖进 Blender）
7. 卡片右上角 ★ 收藏；结果栏「★ 收藏夹」只看收藏；「导出全部」打包下载 zip。

**快捷键**：`Ctrl+Enter` 搜索 · `j`/`k` 上下选结果 · `1`–`4` 切视角 · `Esc` 关弹层。

---

## 2. 我的船

1. 左侧「读取」（路径会自动带出，也可点「浏览…」选文件）。
2. 列表每艘显示：名称 · 类型 · 等级（S/A/B/C） · 四项属性 · 是否可预览。
   - 缩略图区可选「只看能预览的」。
   - 固定模型（护卫舰/复古拦截机等）标「固定模型」，没有 3D，显示占位图。
3. 点任意一艘 → 右侧 3D + 属性条 + 部件缩略图。
4. 「导出全部」把当前列表导出成 zip（glb + png + 清单）。

---

## 3. 写回存档（同型换种子）

前提：设置里打开「允许写入」。

1. 在「搜飞船」里选中一艘想要外观的船 → `写回存档…`。
2. 弹窗列出**同型**的船（不同船型的部件树不同，不能跨型），选目标槽位。
3. 确认后：自动备份 → 原子写入 → **重新解码核对** → 成功提示（附备份路径）。
4. 想更保守：勾选「写入副本」时不动原档，生成 `save.edited.hg`；确认满意后改名成 `save.hg` 再进游戏。
5. 失败会自动**回滚**，并告诉你备份在哪。

---

## 4. 星球

1. 进入页面即自动读取**当前星系**（来自存档位置）：坐标、glyphs、星系名、种族、行星数、是否 dissonant、拦截机种子。
2. 行星卡片按生物群系配色，**"你在这里"**标出当前所在行星。
3. 右侧是本星系船池（空间站/货船/护卫舰/哨兵/海盗/虫群），带种子，可点「3D」直接看。
4. 「找星球」：选生物群系 / 哨兵等级 / 是否只要 dissonant → `扫描`：
   - 结果表每行有 glyphs，点「符文」打开传送门符文弹层。
   - 弹层里可「复制」，「置顶到游戏上方」会把 12 个符文贴成置顶窗（不注入游戏，`Esc` 关闭）。

---

## 5. 送进游戏（可选，Windows）

实时通道要游戏在运行，并且有"模板槽"。两种来源：

- **自己的模板**：设置页「生成模板 Mod」→ 把 `starforge-templates` 复制到 `GAMEDATA/MODS/`，重启游戏（8 种船型）。
- **已装 Super Ship Hunter**：无需额外安装，探测里会标 `[SSH]`（只有 sentinel / exotic 两型）。

步骤：

1. 启动游戏并载入存档。
2. 设置页点「只读探测」：应看到对应船型 `✓ 0x…` 与「可写入」。
3. 回「搜飞船」选一艘 → `送进游戏` → 确认。
4. 写入成功会显示模板槽地址；回游戏里用对应领取方式查看。

> 写入**只改模板里的 8 字节种子**，不动你的船和存档；多候选同样可信时会**拒绝写入**。

## 6. 设置与诊断

- 三条路径旁显示 ✓/✗ 与原因；「自动检测」会顺便纠正常见填错（选到 `GAMEDATA`、`Binaries`、甚至 Steam 根目录）。
- 「运行自检」输出各项状态（上游 / 数据 / 存档 / 游戏 / 系统生成 / 实时通道）。
- 命令行等价物（同一个 exe）：

```bat
starforge.exe selfcheck          :: 端到端自检（写入只在存档副本上）
starforge.exe webcheck           :: 只验证网页与静态资源
starforge.exe ships              :: 列存档里的船
starforge.exe live probe         :: 只读探测模板槽
starforge.exe glyph-overlay 1043FEE69929 --click-through
```

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 顶栏「游戏」是红的 | 设置页确认游戏目录指向含 `Binaries` 的那层；点「自动检测」 |
| 3D 区显示"3D 不可用（已用渲染图代替）" | 说明游戏目录没配好或 pak 读不到；看设置页的 ✓/✗ |
| 「我的船」读不到 | 确认存档目录含 `save.hg`；`accountdata.hg` / `mf_*.hg` 不是玩家存档 |
| 写回按钮是灰的 | 设置里打开「允许写入」 |
| 符文显示成字母 | 缺 BC7 解码器（发布包已内置 `texture2ddecoder`）；源码运行时 `pip install texture2ddecoder` |
| 双击没有窗口 | 看看是否被 WebView2 拦截：程序会退回浏览器并把原因写进 `%USERPROFILE%\.starforge\logs\` |
| 想彻底卸载 | 删程序目录；`%USERPROFILE%\.starforge`（设置/缓存）与存档旁的 `.bak` 自行决定保留 |
