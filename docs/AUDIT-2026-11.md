## 2. 会误导读者的具体错误

### 2.1 一级：会导致错误操作、无法复现，或把“已废弃方案”当成现行方案

**E1｜`ARCHITECTURE.md` 描述了两层并不存在的目录，却被索引为“当前实现为准”**

- 原文：「`application/` 用例编排、任务、状态、错误映射」「`ui/` PySide6 页面、组件、控制器」（`docs/ARCHITECTURE.md:62`、`:83`）
- 原文（索引）：「当前实现以 ARCHITECTURE / UI-REDESIGN / FEATURE-MAP / GAP-ANALYSIS / PLAN-V4 为准」（`docs/README.md:22`）
- 代码事实：
  - `Test-Path starforge/application`、`Test-Path starforge/ui` 均为 **false**；实际是 `starforge/services/`（`services/__init__.py:102 class Services`）与 `starforge/app/`（`app/shell.py:109-117` 注册 7 个页面）。
  - 文中作为“目标设计”的 `AppContext` 其实已经落地，但不在 `ui/context.py`，而在 `starforge/app/context.py:12`。
- 影响：新人按文档找 `application/`/`ui/` 会直接卡住；做重构计划会重复实现已完成的东西。

**E2｜`ARCHITECTURE.md` 的体量/测试数字全部过期**

- 原文：「`services/__init__.py` 565 行」「`web/routes.py` 782 行」「现有 243 项 pytest 全保留」「`app/pages/live.py` 393」「`desktop.py` 旧 pywebview 外壳」（`:30`、`:32`、`:211`、`:45`、`:22`）
- 代码事实（`[System.IO.File]::ReadAllLines` 统计）：
  - `services/__init__.py` **1393 行 / 74 个方法**；
  - `web/routes.py` **765 行 / 44 条路由装饰器**；
  - 测试 **51 个 `.py`（50 个 `test_*.py`）、433 个 `def test_`**；
  - `app/pages/live.py`、`app/pages/search.py` **不存在**（是 `game_link.py` 997 行、`ship_lab.py` 1224 行）；
  - `starforge/desktop.py` **不存在**（`__main__.py:33-39` 明确 `--browser` 已移除）。
- 影响：所有“按规模评估工作量”的讨论都建立在 1/2 以下的数字上。

**E3｜根 `README.md` 仍把“浏览器 WebGL 查看器”当卖点，徽章停在 v0.1**

- 原文：「真 3D 预览（读你自己的游戏 pak）+ **浏览器内可旋转**」「浏览器里是可旋转的真 3D（WebGL）」（`README.md:17`、`:48`）；徽章 `status-v0.1 开发中`（`:6`）
- 代码事实：
  - 仓库内 `.html/.js/.css` 文件数 **0**；
  - `starforge/web/app.py:1-4` 写明“API-only，不再提供静态网页”，`create_app` 使用 `static_folder=None`（`:31`），`GET /` 返回 JSON（`:80-83`）；
  - 3D 只在原生 `starforge/app/widgets/ship_viewer.py`（522 行）里；
  - 版本 `0.14.9`（`starforge/__init__.py`）。
- 影响：用户会找浏览器入口；发布说明与徽章自相矛盾。

**E4｜`VERIFY-AGENT-WINDOWS.md` 教用户改游戏目录里的 `winmm.dll`（现行实现完全不这么做）**

- 原文：「备份原来的 `Binaries\winmm.dll` 为 `winmm.dll.starforge-bak`」「放入我们的同名代理 DLL」「Steam 校验会提示“文件被替换”——点忽略即可」「卸载 → `winmm.dll` 从备份还原」（`docs/VERIFY-AGENT-WINDOWS.md:91-93`、`:123`；红线 `:130`）
- 代码事实：
  - `install_mod()` 只做一件事：把 `starforge/agent/starforge_agent.py` 复制到 `~/.starforge/agent/starforge_agent.py`（`live/agent_install.py:511-517`）；
  - agent 是 pymhf 单文件 Python Mod，`# /// script` 元数据声明 `NMSpy==185034.0` + `pymhf[http_api]==0.2.5`（`agent/starforge_agent.py:1-18`），**不写 `winmm.dll`、不进 PCBANKS**；
  - 安装/启动/状态都在 `live/agent_install.py`（787 行）。
- 影响：这是**最危险**的一条——按文档操作会改动游戏安装目录，而且得到的通道根本不会工作；同时与“默认不改游戏目录”的产品承诺冲突。

**E5｜`AGENT-INJECT-CRASH.md` 内部有三套互斥结论，且都以“结论/最终结论”口吻出现**

- 原文 A：「注入时机不再有顺序要求」，随后给出“先注入后进存档 ✓ / 先进存档后注入 ✓”（§10.1）
- 原文 B：「不要用 pymhf 直接启动 `NMS.exe`」「用 Steam 正常启动游戏…再调用 starforge 的注入」（§10.3）
- 原文 C：「**最终结论：NMS 会主动关闭注入**」（§12 标题）
- 原文 D：「**崩溃的直接原因是注入时机，不是运行时版本**」「闪退是“每帧补绑 hook”引入的回归」「当前稳定操作顺序（**有顺序要求**）」（§8、§13.1、§13.3）
- 代码事实：
  - `launch(attach=True)` **默认直接抛错**，只有 `STARFORGE_ALLOW_ATTACH_INJECT=1` 才放行（`agent_install.py:605-610`）；
  - 应用实际走 `attach=False`，并用 `start_paused=True` 注入（`:648-664`）；
  - 绑定改为 `@one_shot @nms.cTkFSM.StateChange.after`（`starforge_agent.py:429-440`），不是每帧 hook。
- 影响：读者会得出“agent 不可用/随便什么时候注入都行/必须 Steam 先启动”三种互相矛盾的结论；其中两种会导致注入失败或闪退。

**E6｜`AGENT-PROTOCOL.md` 的命令表是“另一套不存在的协议”，`starforge agent hello` 还在按它输出**

- 原文：命令表含 `player.ua`、`player.position`、`ship.read`、`ship.write_seed`、`ship.write_class`、`teleport.system`、`scan.planet`、`debug.flags`（`docs/AGENT-PROTOCOL.md` §3）；「`starforge agent hello` ✅ 已有：打印 13 项能力表（全部 `available=false` + `reason`）」（`:140`）

  - 真实 Mod 有 **12 个端点**：`/hello`、`/player`、`/system`、`/planet`、`/planet/scan`、`/ships`、`/admin/reload`、`/teleport`、`/teleport/portal`、`/restore`、`/scan`、`/scan/instant`（`starforge_agent.py:478-860`）；
  - CLI 的能力表仍是旧 13 个名字（`__main__.py:275-289` 的 `_AGENT_CAPABILITIES`），**与真实端点没有任何一项同名**；连接成功后只读项会被标成 `available=true`（`__main__.py:375-386`），并非“全 false”。
- 影响：任何人按协议文档写脚本/做联调都会 404；`agent hello` 的输出会让人误判“CLI 与 agent 是同一套能力模型”。

## 5. 复核方式与统计口径（可复现）

> Windows PowerShell 5.1 的 `Get-Content` 默认按 ANSI 解码 UTF-8 中文，可能把换行字节并进多字节字符，**行数会偏少**（本次实测 `services/__init__.py` 被读成 1365 行，实际 1393）。请用 `[System.IO.File]::ReadAllLines()`。

```powershell
# 行数（正确口径）
[System.IO.File]::ReadAllLines("starforge/services/__init__.py").Count      # 1393
[System.IO.File]::ReadAllLines("starforge/web/routes.py").Count             # 765
[System.IO.File]::ReadAllLines("starforge/agent/starforge_agent.py").Count  # 860

# 路由 / 端点 / 服务方法 / 测试
```
