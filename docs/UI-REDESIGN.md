# UI 重构设计 · Starforge Command Deck

> 目标：不再沿用旧网页的“三栏表单 + 卡片列表”思维，重做成原生桌面情报台。
> 约束：PySide6 Widgets、Windows 10/11、键盘优先、信息密度高但不拥挤、3D 是主体而不是附属。

---

## 1. 设计方向

**一句话**：像“星际指挥舱”，不是“网页后台”。

- 深空底色 + 低饱和面板 + 琥珀/青色点缀；
- 一屏一个主动作，操作结果就地反馈；
- 3D 视口占据主视野，筛选/结果/属性围绕它；
- 任务、日志、agent 状态收在底部可折叠 Dock，不打断主流程；
- 所有长任务可取消、可看 ETA、可离开页面继续跑。

---

## 2. 主窗口结构

```
┌────────────────────────────────────────────────────────────────────────────┐
│ Command Bar  [STARFORGE]  当前页/面包屑        ⌘K 命令面板   状态芯片  账号/日志 │
├──────┬──────────────────────────────────────────────────────┬──────────────┤
│ Rail │ Workspace                                             │ Inspector    │
│ 72px │                                                      │ 360–460px    │
│ Home │  页面自己的主内容：卡片 / 网格 / 表格 / 3D             │ 选中对象详情  │
│ Lab  │                                                      │ 主操作       │
│ Fleet│                                                      │ 属性/部件     │
│ Galaxy│                                                     │ 安全提示     │
│ Link │                                                      │              │
│ Set  │                                                      │              │
├──────┴──────────────────────────────────────────────────────┴──────────────┤
│ Dock（可折叠）：任务进度 · 日志 · agent 控制台 · 传送/扫描状态               │
└────────────────────────────────────────────────────────────────────────────┘
```

- **Command Bar**：全局状态（数据/存档/游戏/写入/agent）+ 命令面板 + 通知。
- **Rail**：6 个一级入口，图标 + 短标签；当前页用琥珀竖线标识。
- **Workspace**：页面主区，不再固定三栏；根据页面切换为网格/表格/星图/控制台。
- **Inspector**：只显示“当前选中对象”，可折叠；宽度可拖拽记忆。
- **Dock**：任务、日志、agent 输出；默认收起，有任务时自动弹出。

## 3. 页面重设计

### 3.1 Home · 今日战报

- 顶部四张状态卡：当前星系 / 当前船 / 最近搜索 / agent 状态。
- 中部“快速开始”：找船、看我的船、找星球、连接游戏。
- 底部“最近活动”：最近 5 条搜索/写入/传送记录，可一键重开。

### 3.2 Ship Lab · 飞船实验室

- 左：条件构建器（船型、涂装、部件组、预算），用 **chips** 表达条件，已选条件可拖动排序。
- 中：结果“星座网格”，卡片显示 3D 缩略图、种子、命中条件；支持多选加入对比托盘。
- 右：Inspector，原生 3D + 部件图 + 写回/导出/收藏。
- 底：任务时间线（已测种子、速率、ETA、取消）。

### 3.3 Fleet · 我的船队

- 船队视图：大卡片 + 等级/属性条；支持表格/卡片切换。
- 对比托盘：最多 3 艘并排 3D + 属性差异高亮。
- 写回流程做成右侧 Inspector 内的“提交面板”，不再弹大对话框。
- 同伴/护卫舰作为 Fleet 的子标签，不单独占一级导航。

### 3.4 Galaxy · 星图与星球

- 顶部：当前星系 hero 卡（名称、种族、经济、dissonant、glyphs）。
- 中：行星卡片（群系色带、天气、哨兵、资源、是否拦截机）。
- 右：目标星球详情 + 符文条 + “复制地址/置顶显示”。
- 扫描过滤做成顶部条件条，结果即时刷新；银河索引用虚拟表格。

### 3.5 Game Link · 游戏内通道

- 三步状态机：`运行时 → 注入 → 已连接`，每步一个明确按钮和状态。
- 连接后显示实时遥测：玩家 UA、位置、当前行星、船槽。
- 高风险操作（传送/扫描/还原）放在独立“安全区”，需要二次确认。
- 日志与 pymhf 输出直接显示在页面内，不需要 PowerShell。

### 3.6 Settings · 设置与诊断

- 路径、数据、外观、性能、高级（实验性开关）。
- 诊断用可复制的 JSON 卡片，不再是一大段文本。
- 一键“导出诊断包”（日志 + 配置 + build 指纹）。

---

## 6. 交互约定

- `Ctrl+K` 命令面板；`Ctrl+Enter` 开始搜索；`Esc` 关闭 Inspector/Dock。
- 结果网格 `←/→/↑/↓` 移动选择，`Enter` 打开 3D，`W` 写回，`E` 导出。
- 所有长任务进入 JobDock，可取消；离开页面不中断。
- 危险操作必须显示“会发生什么 + 如何还原”。
- 关闭窗口时若有任务/agent 注入，先提示并安全收尾。
- 所有错误给“原因 + 下一步”，不直接抛 Python 异常文本。

| UI-3 | Ship Lab / Fleet 迁移 | 搜船→3D→写回全流程 |
| UI-4 | Galaxy / Game Link / Settings 迁移 | 扫描/传送/诊断全流程 |
| UI-5 | 视觉打磨、DPI、键盘、无障碍 | 1920/2560/4K 截图通过 |

**发布策略**：UI-1 到 UI-4 全部本地跑通、截图确认后再打一个版本；期间不推送中间包。
