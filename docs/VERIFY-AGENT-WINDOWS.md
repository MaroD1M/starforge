# Windows 实机验证单（M4 之前 / 之中各一轮）

> 用途：把"只能在你机器上完成的事"压缩成 **15 分钟、零风险、可回报** 的两轮操作。
> 第一轮**现在就能做**（不改任何文件、不碰内存）；第二轮要等 agent 骨架（M4）落地后做。
> 回报时照第 4 节的 5 项贴，我据此决定签名与偏移表，不需要你猜任何术语。

---

## 0. 前置（2 分钟）

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| 游戏 | 单人模式，正常进到存档（多人不要用，写能力会自动禁用） |
| 应用 | 最新 `starforge.exe`（v0.12.2-beta 或之后），能正常出窗口 |
| 权限 | 普通用户即可；**不需要管理员** |
| 时间 | 第一轮 8 分钟，第二轮 15 分钟 |

> 全程**不修改游戏目录、不写内存、不动存档**（第一轮连游戏都不用重启）。

---

## 1. 第一轮：只读探测（现在就能做，8 分钟）

### 1.1 采集"游戏指纹"（30 秒）

在 PowerShell 里跑（把路径换成你的游戏根目录）：

```powershell
$exe = "C:\Program Files (x86)\Steam\steamapps\common\No Man's Sky\Binaries\NMS.exe"
$f = Get-Item $exe
"path   : $($f.FullName)"
"size   : $($f.Length)"
"mtime  : $($f.LastWriteTimeUtc.ToString('o'))"
"version: $((Get-Item $exe).VersionInfo.FileVersion)"
"sha256 : $((Get-FileHash $exe -Algorithm SHA256).Hash)"
```

这几行就是 agent 将来用来"认出这是哪一版游戏"的指纹。**同一个游戏版本这几行必须完全一致**，
所以先存一份（我会把它写进 `addressbook`）。

### 1.2 跑只读探测（1 分钟）

1. **先启动游戏并进到存档**（停在空间站或行星上都行）。
2. 开一个 PowerShell，进到应用目录，跑：

```powershell
.\starforge.exe live probe
```

3. 把输出整段复制下来。预期三种结果：

| 输出 | 含义 | 下一步 |
|---|---|---|
| `已找到 NMS.exe（pid …）` + 各模板槽一行 | 探测成功——只读，没写任何东西 | 进 1.3 |
| `实时通道仅支持 Windows…` | 跑到了非 Windows 分支（多半是跑在 WSL 里） | 改用 Windows 原生 PowerShell |
| `找不到 NMS.exe` | 进程名或权限问题 | 确认游戏真的在跑；仍失败就把任务管理器里的进程名截图给我 |

### 1.3 对照游戏内事实（3 分钟）

在游戏里看三个数并记下来：

1. 当前**星系名**（星系图里那个）与**信号增幅器坐标**（`XXXX:YYYY:ZZZZ:SSSS` 形式）
2. 当前**行星数量**
3. 你所在行星的**生物群系**（茂盛 / 冰冻 / 剧毒 / 焦土 / 荒芜 …）与**哨兵等级**

然后在应用里点「星球 → 刷新」，看它读出来的当前星系是否与游戏一致。

### 1.4 回报（照抄这 5 项）

```
1) 指纹：size / mtime / sha256（1.1 的四行）
2) live probe 完整输出
3) 游戏内：星系名 + 坐标 + 行星数 + 你行星的生物群系/哨兵等级
4) 应用里「星球」页显示的：UA + 坐标 + glyphs + 行星数
5) 任何报错原文（窗口里的红字或 PowerShell 的整段）
```

**第一轮做完就够我推进 M4 的签名表与偏移校验了。**

---

## 2. 第二轮：agent 骨架（M4 落地后做，15 分钟）

> 这一轮仍然**只读**：`hello` + 5 条读命令。写能力（传送/扫描/写船/调试开关）要等这一轮数据对得上才开。

### 2.1 安装 agent（3 分钟）

应用 → 设置 → 「游戏内模块」→ **安装**。它做三件事（都可逆）：

1. 备份原来的 `Binaries\winmm.dll` 为 `winmm.dll.starforge-bak`
2. 放入我们的同名代理 DLL（导出表与系统 `winmm.dll` 一致，游戏照常启动）
3. 写 `%LOCALAPPDATA%\starforge\agent\install.json`（记录版本与备份路径）

游戏**不需要**重装，Steam 校验会提示"文件被替换"——这是预期，点忽略即可。

### 2.2 启动与握手（2 分钟）

1. 启动游戏，进存档
2. 应用 → 游戏内页 → 应出现状态芯片 **「agent ready · build=…」**
3. 跑一次：

```powershell
.\starforge.exe agent hello
```

预期输出一张 13 项能力表（每项 `available / risk`）。

### 2.3 只读对表（6 分钟）

| # | 应用里显示 | 游戏里看到的 | 判定 |
|---|---|---|---|
| 1 | 当前 UA + 坐标 | 信号增幅器坐标换算后一致 | 一致=通过 |
| 2 | 当前行星索引 | 你站的那颗（第几颗） | 一致=通过 |
| 3 | 本星系船池 50 条 | 空间站能刷的船型与数量 | 类型对得上=通过 |
| 4 | 我的船（等级/属性） | 飞船上看到的等级与四项属性 | 数值一致=通过 |
| 5 | 行星实时字段 | 扫描仪给的名字/天气/哨兵 | 文字一致=通过 |

任何一项不一致，把**两边的截图**一起发我（这是校准偏移的唯一依据）。

### 2.4 卸载（1 分钟，可选）

设置 → 「游戏内模块」→ **卸载** → 目录恢复原样（`winmm.dll` 从备份还原、manifest 删除）。
卸载后再跑一次游戏确认能正常启动。

---

## 3. 红线（这一轮绝对不做）

1. **不改**游戏目录里除 `winmm.dll`（含 `.starforge-bak`）以外的任何文件
2. **不写**内存（第二轮全部命令都是 `risk: low` 的只读）
3. **不进**多人模式
4. **不传**任何存档/账号信息（日志只留本地，默认不上报）

## 5. 我做这部分时要用的东西（你不需要操作）

| 我要的输入 | 用途 |
|---|---|
| `sha256(NMS.exe)` | 生成 `game_build_id`，绑定地址书 |
| `live probe` 输出 | 确认模板槽签名在这版仍然命中（`live/writer.py` 的多候选+评分） |
| 游戏内坐标截图 | 校准 `GcPlayerState` 的 UA/位置偏移 |
| 船池类型对照 | 校准 `system.current` 的船池结构与 `systemgen` 是否同源 |
| 属性数值对照 | 校准 `ship.read` 的四项属性字段 |

有这些我就能把 T1（签名库）、T4（只读通道）从"代码完成"变成"实机通过"，然后才动手 T5–T7（传送/扫描/写船）。
