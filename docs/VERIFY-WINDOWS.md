# Windows 真机验收清单

> 开发环境在 Linux，凡是必须"开游戏"的环节我无法代跑。这份清单把每个待验证点写成可勾选的小步骤，
> 你照着点一遍，把结果（成功/失败 + 截图或报错）发回来即可。
> 建议顺序：A → B → C → D → E，每段都可独立完成。

---

## 0. 准备

- [ ] 下载 `starforge-v0.9.0-beta-win64.zip`，解压到任意目录（不要放在游戏目录里）
- [ ] 确认已装 Python？**不需要**——压缩包自带运行时
- [ ] 备份存档：把 `%APPDATA%\HelloGames\NMS\st_<你的ID>\` 整个复制一份到别处

启动：

```bat
starforge\starforge.exe            :: 或双击 starforge.exe
```

浏览器应自动打开 `http://127.0.0.1:<随机端口>/`。

- [ ] 页面能打开，顶栏显示版本号与预览档位

---

## A. 路径与自检（不需要开游戏）

设置页：

- [ ] **游戏目录**填到 `...\No Man's Sky`（该目录下有 `Binaries\NMS.exe`）→ 保存
- [ ] **存档目录**填到 `...\HelloGames\NMS\st_<你的ID>` → 保存
- [ ] **数据目录**填到 `<游戏目录>\GAMEDATA`
- [ ] 顶栏档位从 `L0 部件图` 变为 **`L1 真 3D`**
- [ ] 点「运行自检」，`diagOut` 里 `preview_level` 为 `L1`、`catalog.ship` 为 8、`system.available` 为 `true`

**通过标准**：以上全绿。若档位仍是 L0，说明游戏目录填错（要填含 `Binaries` 的那层）。

---

## B. 搜索 + 3D（不需要开游戏）

- [ ] 「搜飞船」页：船型选 `sentinel`
- [ ] 部件树里点 2–3 个部件（变绿＝想要）
- [ ] 点「开始搜索」→ 顶栏出现进度条，几秒内出结果网格
- [ ] 网格里每张卡片都有缩略图（不是空白）
- [ ] 点任意卡片 → 右侧出现**可拖拽旋转**的 3D 船
- [ ] 试着滚轮缩放、点「俯视」「侧视」「自动旋转」
- [ ] 点「下载 glb」，用任意查看器（Windows「3D 查看器」/Blender）能打开

**通过标准**：3D 能转、能缩、能导出。若 3D 区显示"已用服务端渲染图代替"，把红字报错发我。

---

## C. 存档图鉴 + 写回（不需要开游戏，但要退出游戏）

- [ ] 「我的船」页 → 点「打开存档」→ 左侧列出你的船（艘数应与游戏内一致）
- [ ] 点一艘 → 右侧 3D + 种子 + 部件数
- [ ] 回到「搜飞船」，搜到一艘**同船型**的船，点它 → 右侧出现「写回存档…」
- [ ] 点「写回存档…」→ 按提示填目标槽位 → 确认
- [ ] 提示"写入成功，已通过读回校验"，并给出备份路径
- [ ] 检查存档目录里出现了 `save.hg.<时间戳>.bak`
- [ ] 启动游戏载入存档，进游戏看那艘船的外观是否变成你选的那艘

**通过标准**：游戏内外观与预览一致。若不一致：立刻用备份恢复（`save.hg.<时间戳>.bak` 覆盖回 `save.hg`），并把两个种子发我。

---

## D. 符文浮窗（不需要开游戏）

- [ ] 「星球」页 → 点「看当前星系」→ 右侧出现行星表与船池、拦截机种子
- [ ] 点「显示本星系符文」→ 弹层里出现 **12 个符文**（不是 12 个字母）
  - 若显示的是字母/数字而非游戏图标：说明 BC7 解码依赖缺失，属已知降级，告诉我我给你补
- [ ] 点「复制符文」，粘贴到记事本确认是 12 位十六进制
- [ ] 点「弹出为置顶窗口」，得到一个不抢焦点的小窗
- [ ] 游戏改「无边框窗口」模式后，这个小窗能显示在游戏上方
- [ ] 照着 12 个符文在游戏内传送门输入，能到达对应星系

**命令行方式**（可选，更省事）：

```bat
starforge\starforge.exe glyph-overlay 1043FEE69929 --click-through
```

- [ ] 出现置顶符文条；按 Esc 可关闭；加 `--click-through` 后鼠标能穿透到游戏

**通过标准**：符文与游戏传送门界面一致（逐个对照）。

---

## E. 实时通道（需要开游戏，风险最高，最后做）

> **快捷通道**：如果你已经装了 **Super Ship Hunter** 的 Mod，可以跳过"装我们的模板"这一步，
> 直接测 `sentinel` / `exotic` 两型——starforge 会自动识别并复用它的两个槽（探测里标 `[SSH兼容]`）。

先装模板 Mod（可选，装了就 8 种船型都能测）：

- [ ] 设置页 →「生成模板 Mod」→ 记下生成路径
- [ ] 把 `starforge-templates` 整个文件夹复制到 `<游戏目录>\GAMEDATA\MODS\`
- [ ] 重启游戏并载入存档

然后（**先只读探测，确认能定位，再写入**）：

- [ ] 设置页点「探测模板槽（只读）」→ `diagOut` 里应看到 8 行，
      其中 `sentinel` 一行是 `✓ 0x...`、`可写入`
      - 若显示 `✗ 没有命中：模板 Mod 可能没装/没生效` → 回到上一步检查目录
      - **把这段文本整段复制发我**（不含任何账号/存档信息，只有内存地址）

- [ ] 设置页打开「允许写入」
- [ ] 确认「实时通道」状态显示 **可用 · 已连上 NMS.exe（PID …）**
- [ ] 搜索到一艘 `sentinel` → 详情页出现「送进游戏（模板槽）」→ 点它 → 确认
- [ ] 提示"已写入模板槽（地址 0x…）"
- [ ] 在游戏内用对应方式领取船（例如哨兵拦截机信号），检查外观是否与预览一致

**失败时的常见报错与含义**：

| 报错 | 含义 | 怎么办 |
|---|---|---|
| 没找到 NMS.exe | 游戏没启动或权限不足 | 以管理员身份运行 starforge |
| 没找到 sentinel 的模板槽 | 模板 Mod 没装/没生效 | 检查 `GAMEDATA\MODS\starforge-templates\METADATA\...` 是否存在 |
| 命中多个同样可信的候选 | 内存里有两份同样的模板 | 正常保护：请重启游戏后再试 |
| 回读校验失败 | 写入没生效（页保护） | 管理员运行；仍失败就把地址发我 |

**风险提示**：这一段会写游戏内存。若出现闪退，属预期风险——存档不会被破坏（实时通道不碰存档），重启游戏即可。
