# 设计方案 v2（重构版）

> 出发点：v0.11.x 已经能跑、能搜、能写回，但四件事没做好——
> ① 部件只有英文内部名、看不到部件本身；② 3D 观感与成熟项目有差距；
> ③ 仍要关心"路径/外部资源"；④ 星球页字段是英文，界面还不够现代。
> 本文是把这四件事做成"产品的样子"的方案与执行结果。

## 一、问题与根因（逐条对上你的反馈）

| 你的反馈 | 根因 | 处理 |
|---|---|---|
| 部件筛选没有中文名称 | 游戏内部是模型节点名（`_PIT_A`），官方无中文；我们直接显示了原名 | 新增 `starforge/zh.py`：198 个插槽组 + 部件词根的中英映射，编号保留（`_LIGHTS_C1` → 灯光 C1）；重名自动编号 |
| 看不到部件预览 | 之前只有 Gagarin 的 96px 游戏图标，且很多部件没有图标 | 新增**部件级 3D 预览**：从游戏几何里单独取出该部件并光栅化（座舱/机翼/灯组各自可辨），失败退图标、再退占位图（永远 200） |
| 3D 不像完整建模 | 缩略图是**点云**渲染（只在顶点落点，看起来散）；WebGL 又曾有黑屏 bug | 新增**三角光栅化**（z-buffer + Lambert 面着色 + 背面剔除），替换点云；黑屏 bug 已修（WebGL2 + uint 索引 + 画布自检） |
| 还要填路径 / 还要别的项目资源 | 上一版仍会要求 Steam 目录；Gagarin 数据被当成必需 | 数据层内置（Shipwright vendor）；部件树缺 Gagarin 时**从游戏资源推导**；路径自动检测覆盖注册表/`libraryfolders.vdf`/多磁盘，并能纠正"选错层"（GAMEDATA/Binaries/Steam 根） |
| 星球字段英文 | 上游字段是英文枚举 | 群系/哨兵/种族/船池类别全部中文化（`Lush → 茂盛`、`corrupted → 腐化`、`Gek → 吉克`、`space station → 空间站`） |
| 界面要现代美观全面 | 旧界面是裸表单 | 左导航 + 三栏工作区、状态芯片、应用内对话框、卡片网格、属性条、收藏夹、导出、快捷键、URL 直达 |

## 二、渲染分层（为什么"像不像模型"差这么多）

| 层级 | 用途 | 实现 | 实测 |
|---|---|---|---|
| **L3 实时 3D** | 详情面板可旋转 | GLB → WebGL（三角形 + 面法线着色 + 种子配色） | 拖动流畅；画布自检失败自动退化 |
| **L2 光栅缩略图** | 结果网格 / 导出 PNG | numpy z-buffer 光栅化，480px ss=2 | 4.0s 冷、缓存后直出 |
| **L1 点云缩略图** | 极快预览（不用） | 现已降级为兜底 | — |
| **L0 部件图** | 无游戏文件时 | Gagarin 图标 / 占位图 | 即时 |

关键取舍：**网格用光栅化（观感）**，冷启动慢的部分交给**启动预热 + 磁盘缓存**；单部件图用同一套光栅化，但只取该部件几何（与"固定件"求差集得到），所以座舱/机翼/灯组能分清。

## 四、零配置（目标是"双击就能用"）

1. 数据层随包（NMS-Shipwright, MIT，vendor 0.5 MB）
2. 部件树：Gagarin `catalog.txt` → 缺失时从游戏 pak 推导（53 组 / 272 部件，0 秒）
3. 路径：`NMS_DIR` → Shipwright `gamepath` → 注册表 `SteamPath` → 各库 `libraryfolders.vdf` → 多磁盘扫描；
   并自动纠正选错层（`…\GAMEDATA` / `…\Binaries` / Steam 根目录）
4. 存档：默认 `save.hg` → `save2.hg`，只认玩家存档（`accountdata.hg`/`mf_*.hg` 会给出明确原因）
5. 缺项时只弹一次向导，能自动填就不打扰

## 七、贴图管线现状（重要，别误解）

- 已实现：`tex.dds_bytes()`（原样取 DDS）、`tex.rgba()`（texture2ddecoder 解 BC1/3/4/5/7）、
  `render.rasterize(textures=…)`（按 UV 采样并乘光照）、`/api/texture`（给 WebGL 用）
- 会用真实贴图的条件：`shiptex` 能读到材质描述符（`materials/**.MATERIAL.MBIN`）。
  本开发沙箱里该目录为空（解不出），所以真实贴图**未能本地验证**；用自造 BC1 DDS 验证了解析与解码链路。
- 依赖关系：贴图缺失时自动退回"种子配色"，功能不受影响。
