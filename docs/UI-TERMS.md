# 界面术语表（UI Terms）

本表用于 starforge 原生界面（`starforge/app/`）与相关界面文案，统一中英文用词。
原则：界面默认使用中文；专有技术名词可保留英文，但必须附中文解释，或放进括号/工具提示。

## 核心术语

| 中文 | 英文 | 使用场景 |
| --- | --- | --- |
| 飞船 | ship | 单艘飞船的名称、标题、按钮与详情 |
| 船队 | fleet | “我的船队”、导出船队、船队列表 |
| 星图 | galaxy map | 导航、页面标题、星系浏览入口 |
| 星系 | star system | 星图内的星系层级、坐标与筛选 |
| 行星 | planet | 星图/星系详情中的行星信息 |
| 符文 | glyph | 传送门符文；保留 `glyphs` 时写作“传送门符文（glyphs）” |
| 存档 | save | 存档目录、读取存档、存档槽位 |
| 写入 | write | 将飞船数据写入存档 |
| 写入副本 | write copy | 不覆盖原存档，另存一份写入结果 |
| 备份 | backup | 写入前自动备份、备份列表 |
| 恢复 | restore | 从备份恢复存档 |
| 游戏内代理 | in-game agent | 连接游戏、运行时状态、代理安装状态 |
| 组件 | component | 代理/运行时组件、缺失组件提示 |
| 搜索 | search | 开始搜索、搜索预算、搜索进度 |
| 筛选 | filter | 按船型、部件、涂装筛选结果 |
| 收藏 | favorite | 收藏飞船、收藏夹 |
| 分享码 | share code | `nsh1:` 分享码的复制、导入与校验 |

## 保留英文的技术名词

| 英文/缩写 | 推荐写法 | 说明 |
| --- | --- | --- |
| glb | 3D 模型文件（glb） | 导出模型、文件格式说明 |
| CSV | 表格文件（CSV） | 导出/导入表格数据 |
| glyphs | 传送门符文（glyphs） | 星图/传送门相关文案 |
| JSON | 诊断数据（JSON 格式） | 诊断导出、可复制数据 |
| ZIP | 压缩包（ZIP） | 导出船队/模型压缩包 |
| PNG | 预览图（png） | 截图与缩略图 |
| nsh1: | 分享码（nsh1:） | 飞船分享码前缀 |
| PIT / WING | 部件名（如 PIT / WING） | 游戏内部部件代号 |
| save.hg | 存档文件（save.hg） | 存档文件名 |
| Binaries/NMS.exe | 游戏根目录（含 Binaries/NMS.exe） | 游戏安装路径提示 |
| Qt / PySide6 | 原生界面（Qt/PySide6） | 窗口技术说明 |

## 状态与动作

| 中文 | 英文 | 使用场景 |
| --- | --- | --- |
| 就绪 | ready | 状态栏、数据层状态 |
| 已连接 | connected | 游戏内代理连接状态 |
| 运行时就绪 | runtime ready | 代理运行时可用 |
| 组件缺失 | component missing | 代理运行时缺失 |
| 只读 | read-only | 写入开关关闭 |
| 写入已开 | write enabled | 写入开关打开 |
| 未设置 | not set | 游戏目录/存档目录 |
| 未发现 | not found | 存档自动发现结果 |
| 正在读取 | loading | 读取存档/部件表 |
| 正在导出 | exporting | 导出模型/船队 |
| 已复制 | copied | 分享码、种子复制成功 |
| 已保存 | saved | 设置、截图保存成功 |

## 易混用词

- 用“飞船”，不用“船”单独指代单艘飞船。
- 用“星图”指整体星系地图，用“星系”指单个恒星系统，用“行星”指星球本体。
- 用“写入”描述写入存档动作；“写回”不再作为界面术语。
- 用“备份 / 恢复”成对出现，不用“还原”。
- 不用 `agent` 直接展示给用户，统一写“游戏内代理”。
- 不用 `Inspector` 作为面板标题，统一写“飞船详情”。
- 不用 `Home`、`Dock` 等英文导航名，统一写“概览”“任务栏”。
